📊 Cara Kerja Halaman Data Tersedia

Panduan sederhana untuk memahami bagaimana sistem mengecek kelengkapan data — Rumah Data 2.0 Kota Samarinda

Mudah Dipahami Tanpa Istilah Rumit Untuk Semua Pengguna

1Apa Itu Halaman Data Tersedia?

Bayangkan halaman ini seperti papan pengumuman di kantor yang menunjukkan:

  • Data wilayah mana yang sudah masuk lengkap
  • Data wilayah mana yang baru sebagian
  • Data wilayah mana yang belum diinput sama sekali

Tujuannya supaya petugas tahu data mana yang masih perlu dilengkapi, jadi tidak ada wilayah yang terlewat.

Ada 4 keterangan status yang dipakai:

Status
LENGKAP Semua wilayah sudah ada
Status
SEBAGIAN Masih ada yang kurang
Status
BELUM ADA Masih kosong
Status
TIDAK DIKETAHUI Ada masalah teknis

5Aturan Pemberian Status

Sistem memberi tanda berdasarkan aturan sederhana ini:

TandaKapan DiberikanTampilan di Layar
LENGKAP Semua wilayah dalam satu kecamatan/kelurahan sudah ada datanya untuk periode yang dipilih ✅ Kotak hijau dengan tanda centang. Tidak perlu impor data lagi.
SEBAGIAN Sebagian wilayah sudah ada, tapi masih ada wilayah yang belum ⚠️ Kotak kuning + daftar nama wilayah yang belum + tombol untuk impor data.
BELUM ADA Tidak ada satupun wilayah yang punya data untuk periode itu ❌ Kotak merah + tombol untuk impor data.
TIDAK DIKETAHUI Ada masalah teknis, misalnya tabel datanya hilang atau salah pengaturan ❓ Kotak abu-abu + pesan agar admin sistem dihubungi.

7Perjalanan Status Data dari Awal sampai Lengkap

Status data bisa berubah-ubah seiring waktu. Begini alurnya:

stateDiagram-v2 [*] --> BelumAda : Data baru, belum ada apapun BelumAda --> Sebagian : Petugas impor data sebagian wilayah BelumAda --> Lengkap : Petugas impor data semua wilayah Sebagian --> Lengkap : Lengkapi wilayah yang tersisa Lengkap --> Sebagian : Ada data yang dihapus Sebagian --> BelumAda : Semua data dihapus Lengkap --> BelumAda : Semua data dihapus [*] --> TidakDiketahui : Ada masalah pengaturan TidakDiketahui --> BelumAda : Masalah sudah diperbaiki
💡 Catatan: dalam pemakaian normal, perjalanan yang umum adalah dari BELUM ADA → SEBAGIAN → LENGKAP. Status Tidak Diketahui jarang terjadi dan biasanya butuh bantuan admin sistem.

8Ringkasan Singkat

  • Halaman Data Tersedia berfungsi seperti papan pemantauan kelengkapan data per wilayah dan periode.
  • Sistem otomatis menghitung berapa wilayah sudah ada datanya dan berapa yang belum.
  • Hasilnya ditandai dengan 4 warna agar mudah dibaca: LENGKAP SEBAGIAN BELUM ADA TIDAK DIKETAHUI.
  • Admin bisa langsung lompat dari halaman ini ke halaman impor data lewat tombol khusus.
  • Pengguna biasa cuma bisa cek status — tidak bisa lihat detail wilayah, tetap aman.
