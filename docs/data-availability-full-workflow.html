1Gambaran Umum

Fitur Data Tersedia adalah halaman yang membantu petugas memantau kelengkapan data di sistem Rumah Data. Ibarat papan kontrol di pos petugas, halaman ini menunjukkan:

  • Jenis data apa saja yang dikelola sistem
  • Kapan periode datanya (semester dan tahun)
  • Wilayah mana yang sudah terisi datanya
  • Wilayah mana yang masih perlu dilengkapi

Dengan begitu, petugas tidak perlu mengecek satu-satu — semuanya tampil di satu halaman.

🎯 Tujuan utama: agar tidak ada wilayah yang terlewat saat input data, dan agar pengguna laporan tidak melihat halaman kosong.

2Pemain dalam Sistem

Ada beberapa pihak yang terlibat dalam alur ini:

👨‍💼 Admin
  • Punya akses penuh ke menu Pengaturan
  • Bisa lihat ringkasan semua data
  • Bisa lihat detail wilayah yang belum lengkap
  • Bisa langsung impor data dari halaman ini
👤 Pengguna Biasa
  • Sudah login ke sistem
  • Cuma bisa cek status data per jenis
  • Tidak melihat detail wilayah
  • Dapat info kalau data belum tersedia
⚙️ Sistem Otomatis
  • Cek database setiap kali halaman dibuka
  • Hitung selisih antara wilayah seharusnya dan yang sebenarnya ada
  • Tentukan status: Lengkap, Sebagian, Belum Ada
  • Update tampilan secara otomatis
📋 Daftar Pengaturan
  • Berisi daftar semua jenis data yang dipantau
  • Mencatat tabel database mana yang harus dicek
  • Diatur sekali oleh admin sistem
  • Jadi rujukan untuk semua pengecekan

4Tahap Demi Tahap Secara Detail

📍 Tahap 1 — Persiapan Awal

  1. Pengguna login ke sistem dengan akun masing-masing.
  2. Sistem mengenali jenis pengguna dari hak aksesnya — admin atau pengguna biasa.
  3. Menu yang muncul di sidebar disesuaikan dengan hak akses tersebut.

📍 Tahap 2 — Membuka Halaman Data Tersedia (Admin)

  1. Admin klik menu Pengaturan di sidebar kiri.
  2. Sebuah jendela kecil muncul berisi pilihan: User, Role, Wilayah Kelurahan, dan Data Tersedia.
  3. Admin klik tombol Data Tersedia.
  4. Halaman terbuka dengan tampilan kartu ringkasan dan tabel detail.

📍 Tahap 3 — Sistem Mengisi Filter Otomatis

  1. Sistem baca semua tabel data di database.
  2. Sistem cari tahun-tahun mana saja yang sudah punya data — ini jadi pilihan dropdown tahun.
  3. Pilihan semester sudah tetap: Semester I dan Semester II.
  4. Pilihan jenis data diambil dari daftar pengaturan internal sistem.

📍 Tahap 4 — Pengecekan Kelengkapan Data

  1. Admin pilih Semester dan Tahun yang ingin dicek.
  2. Bisa juga difilter berdasarkan Jenis Data tertentu kalau hanya ingin lihat satu jenis.
  3. Sistem mulai cek satu per satu jenis data ke database.
  4. Untuk setiap jenis, sistem ambil daftar wilayah seharusnya (semua kelurahan aktif).
  5. Sistem ambil daftar wilayah yang sebenarnya sudah punya data di periode itu.
  6. Sistem hitung selisihnya — itulah wilayah yang masih kosong.
💡 Contoh hitung-hitungan: Misalnya Kota Samarinda punya 53 kelurahan. Untuk Data Penduduk Agama Semester 1 Tahun 2025, sistem cek di database — ternyata baru 45 kelurahan yang punya data. Berarti masih ada 8 wilayah yang belum lengkap.

📍 Tahap 5 — Penentuan Status

Berdasarkan hasil hitungan tadi, sistem memberi tanda:

  • Kalau semua wilayah sudah ada datanya → tanda LENGKAP
  • Kalau sebagian saja yang ada → tanda SEBAGIAN
  • Kalau tidak ada satupun → tanda BELUM ADA
  • Kalau ada masalah teknis → tanda TIDAK DIKETAHUI

📍 Tahap 6 — Tampilan ke Layar

  1. Bagian atas: 4 kartu warna berisi total Lengkap, Sebagian, Belum Ada, dan Total Dimensi.
  2. Di bawahnya: filter untuk drill-down.
  3. Lalu: tabel detail berisi setiap jenis data dengan statusnya masing-masing.
  4. Untuk baris yang berstatus Sebagian atau Belum Ada, ada baris tambahan menampilkan nama-nama wilayah yang belum.
  5. Setiap baris yang belum lengkap punya tombol untuk langsung impor data.

📍 Tahap 7 — Tindak Lanjut Admin

  1. Admin lihat ada wilayah yang belum lengkap.
  2. Klik tombol Impor Data di header tabel atau di baris tertentu.
  3. Pindah ke halaman impor, isi formulir, dan upload file Excel.
  4. Sistem simpan ke database, beri pesan berhasil.
  5. Admin kembali ke Halaman Data Tersedia.
  6. Status data langsung berubah — Belum Ada jadi Lengkap atau Sebagian.
