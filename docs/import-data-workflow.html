1Apa Itu Impor Data?

Bayangkan kantor punya banyak data wilayah dalam bentuk file Excel — misalnya jumlah penduduk laki-laki perempuan per kelurahan. Daripada mengetik ulang satu-satu ke sistem, kita pakai fitur Impor Data.

Cukup pilih file Excel-nya, sistem otomatis baca semua isinya dan masukkan ke database — sekali klik selesai untuk ratusan baris.

🎯 Manfaat utama: hemat waktu, tidak salah ketik, dan satu file Excel bisa berisi data ratusan wilayah sekaligus.

2Pemain dalam Sistem

👨‍💼 Petugas Admin
  • Punya hak akses Impor Data
  • Menyiapkan file Excel
  • Memilih jenis data, tahun, semester
  • Klik tombol Impor
📄 File Excel
  • Format harus sesuai template
  • Harus berisi kolom wilayah
  • Harus berisi data wilayah per baris
  • Maksimal 20 MB
⚙️ Sistem Pembaca
  • Buka file Excel
  • Baca isi tiap baris
  • Cek kelengkapan data
  • Simpan ke database
💾 Database
  • Tempat data tersimpan permanen
  • Diatur per jenis data
  • Pisah per tahun + semester
  • Tidak boleh duplikasi

3Persiapan Sebelum Impor

Sebelum melakukan impor, pastikan beberapa hal berikut:

  1. Login sebagai admin yang punya hak akses Impor Data.
  2. Siapkan file Excel dengan format yang sesuai template. Template bisa diunduh dari halaman Impor Data lewat tombol "Format File Import Excel".
  3. Pastikan isi file benar — kolom wilayah terisi semua, angka ditulis sebagai angka (bukan teks), tidak ada baris kosong di tengah.
  4. Tahu jenis data apa yang akan diimpor — misalnya "Penduduk Jenis Kelamin" atau "Disabilitas Pekerjaan".
  5. Pastikan periode benar — semester dan tahun yang akan diimpor.
  6. Cek halaman Data Tersedia dulu untuk lihat apakah data tersebut sudah pernah diimpor sebelumnya.
⚠️ Penting: kalau data dengan kombinasi jenis + tahun + semester yang sama sudah ada di database, sistem akan menolak impor untuk mencegah data ganda.

5Tahap Demi Tahap Secara Detail

📍 Tahap 1 — Membuka Halaman Impor

  1. Petugas login ke sistem dengan akun yang punya hak akses Impor Data.
  2. Klik menu Import Excel di sidebar (di bagian "Import").
  3. Halaman terbuka dengan form yang berisi: pilih tahun, pilih semester, pilih file, dan pilih jenis data.
  4. Di pojok kanan ada tombol "Format File Import Excel" untuk mengunduh template.

📍 Tahap 2 — Mengisi Form Impor

  1. Petugas pilih Tahun dari dropdown (tahun-tahun yang tersedia).
  2. Petugas pilih Semester — Semester I (1) atau Semester II (2).
  3. Klik tombol Choose File, pilih file Excel dari komputer.
  4. Petugas pilih Jenis Data dari dropdown — misalnya "Disabilitas Pekerjaan".
  5. Setelah semua terisi, klik tombol Impor.
ℹ️ Daftar jenis data yang bisa diimpor ada banyak — dari Disabilitas, Kepala Keluarga, Penduduk, Kepemilikan Akta, hingga Struktur Umur. Total sekitar 45 jenis berbeda.

📍 Tahap 3 — Konfirmasi Impor

  1. Sistem tampilkan jendela "Konfirmasi" dengan pesan:
    "Apakah Anda yakin ingin menyimpan data ini?"
  2. Petugas pilih Simpan untuk lanjut, atau Batal untuk membatalkan.
  3. Kalau klik Batal — muncul pesan "Pembatalan, Data tidak disimpan", proses berhenti.
  4. Kalau klik Simpan — sistem mulai proses impor.

📍 Tahap 4 — Pengecekan Awal oleh Sistem

Sebelum membaca file, sistem cek beberapa hal:

  1. Apakah semua field terisi? Tahun, semester, dan file harus ada.
  2. Apakah file ekstensinya benar? Hanya .xlsx, .xls, atau .csv yang diterima.
  3. Apakah ukuran file di bawah 20 MB? Kalau lebih, ditolak.
  4. Apakah jenis data yang dipilih valid? Sistem cek di daftar jenis data yang dikenal.
  5. Apakah data sudah ada? Sistem cek database — kalau untuk kombinasi jenis + tahun + semester sudah ada data, ditolak agar tidak ganda.
⚠️ Penting: kalau ada satu pengecekan yang gagal, proses langsung berhenti dan muncul pesan error. File belum dibaca, database belum disentuh.

📍 Tahap 5 — Membaca dan Menyimpan File

Kalau pengecekan awal lolos, sistem mulai proses inti:

  1. Sistem buka "transaksi database" — semacam kotak pengaman untuk memastikan data tersimpan utuh atau tidak sama sekali.
  2. Untuk file besar (lebih dari 2 MB), sistem alokasikan memori lebih dan waktu lebih lama.
  3. Sistem buka file Excel dan baca baris per baris.
  4. Untuk setiap baris, sistem ambil isi kolom dan simpan ke database.
  5. Setelah semua baris selesai dibaca, sistem tutup transaksi — data resmi tersimpan permanen.
ℹ️ Apa itu transaksi database? Bayangkan seperti membuat kontrak — kalau ada satu pasal yang gagal, seluruh kontrak dibatalkan. Begitu juga dengan impor: kalau ada satu baris gagal disimpan, semua baris yang sudah disimpan ikut dibatalkan. Database tetap bersih.

📍 Tahap 6 — Hasil Akhir

Setelah proses selesai, ada 3 kemungkinan hasil:

HasilApa yang TerjadiPesan ke Petugas
BERHASIL Semua data sudah masuk ke database "Import Berhasil!" lalu halaman di-refresh
DATA SUDAH ADA Tidak ada perubahan di database "Data sudah ada" — petugas perlu hapus dulu data lama atau pilih periode lain
GAGAL Tidak ada data yang tersimpan (otomatis dibatalkan) "Terjadi kesalahan server" + petugas perlu cek file lalu coba lagi

9Penanganan Masalah yang Sering Terjadi

MasalahPenyebab MungkinCara Mengatasi
Pesan "Data Sudah Ada" Kombinasi jenis + tahun + semester sudah pernah diimpor sebelumnya Cek di Halaman Data Tersedia. Kalau memang ingin ganti, hapus data lama dulu via menu manajemen data
Pesan "Format file tidak didukung" File yang dipilih bukan Excel atau CSV Pastikan file punya ekstensi .xlsx, .xls, atau .csv. Konversi kalau perlu
Pesan "Ukuran file melebihi 20 MB" File terlalu besar Pisah file Excel jadi beberapa bagian (per kecamatan misalnya), impor satu-satu
Proses impor lama sekali File besar (>2 MB) atau koneksi lambat Sabar tunggu — sistem otomatis kasih waktu sampai 10 menit untuk file besar. Jangan tutup halaman
Data masuk tapi nilainya semua nol Nama kolom di file Excel tidak sama dengan template Unduh template terbaru lewat tombol "Format File Import Excel", samakan nama kolom persis
Pesan error tidak jelas Ada baris di file yang nilainya kosong padahal harus terisi Buka file Excel, cek baris-baris yang nilainya kosong, isi atau hapus baris kosong di akhir
Tombol Impor tidak merespon JavaScript belum dimuat atau ada error di browser Refresh halaman dengan Ctrl+Shift+R untuk muat ulang dari awal
⚠️ Tips umum: selalu unduh template terbaru sebelum mengisi data. Jangan ubah nama kolom, jangan tambah kolom baru, jangan hapus kolom yang ada. Sistem mengandalkan nama kolom yang persis sama dengan template untuk membaca isi file.
