Catatan Penting: Semua perhitungan dilakukan di level database (SQL), bukan di PHP/aplikasi. Ini adalah pola yang tepat untuk performa — MySQL menangani SUM/GROUP BY langsung pada data besar. Tidak ada algoritma kompleks di PHP; PHP hanya meneruskan parameter filter (tahun, semester, tanggal) dan memformat output JSON.

Zero-Division Protection: Seluruh rumus persentase menggunakan pola IF(SUM(denominator) = 0, 0, (numerator/denominator)*100) untuk mencegah error saat data belum ada.
