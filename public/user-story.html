Fase 1

Planning Phase

1 Des – 14 Des 2024  ·  2 Minggu
Release Planning Desember Minggu 1–2

Pada fase ini tim dan customer melakukan Exploration, Commitment, dan Steering untuk menetapkan scope release pertama berdasarkan prioritas business value.

  • 1
    Exploration — Customer menuliskan user stories; tim mengestimasi story points setiap fitur berdasarkan kompleksitas teknis dan data aktual project.
  • 2
    Commitment — Customer memilih dan memprioritaskan user stories untuk masuk ke release; tim menyanggupi berdasarkan kapasitas (velocity).
  • 3
    Steering — Tim menyusun rencana iterasi; customer dapat mengubah prioritas story selama perencanaan berlangsung.
  • 4
    Output — Daftar 37 user stories terklasifikasi, rencana 11 iterasi @ 2 minggu, dan definisi "Done" untuk setiap story.

Fase 2

Iterations to Release Phase

15 Des 2024 – 17 Mei 2025  ·  11 Iterasi × 2 Minggu
Iterasi 1 — Fondasi Auth & Manajemen Akses 15–28 Des 2024
Focus: Core Infrastructure
US-01 Login US-02 Logout US-03 Ganti Password US-04 Manajemen User US-05 Role & Permission US-34 Wilayah Kelurahan

Membangun fondasi sistem: autentikasi sesi, manajemen pengguna, role & permission (Spatie), dan data referensi wilayah. Tanpa fondasi ini tidak ada fitur lain yang bisa berjalan.

Iterasi 2 — Dashboard & Import Data 29 Des – 11 Jan 2025
Focus: Core Feature — Data Entry
US-07 Dashboard Utama US-08 Import Excel (45 format)

Dashboard sebagai halaman utama pengguna & pipeline import Excel (Maatwebsite) — dua fitur bernilai bisnis tertinggi setelah login, karena semua data laporan bergantung pada import.

Iterasi 3 — Agregat DKB: Data Penduduk 12–25 Jan 2025
Focus: Domain Data — Penduduk
US-09 Agregat Penduduk US-10 Kepala Keluarga

Fitur data penduduk (jenis kelamin, agama, pekerjaan, golongan darah, hubungan keluarga) dan kepala keluarga per kelurahan — data inti yang paling sering diakses petugas.

Iterasi 4 — Agregat DKB: Data Sosial 26 Jan – 8 Feb 2025
Focus: Domain Data — Sosial
US-11 Disabilitas US-12 Pendidikan US-13 Status Kawin

Melengkapi modul Agregat DKB dengan data sosial: disabilitas, pendidikan, dan status kawin. Ketiga data ini mendukung perencanaan program sosial daerah.

Iterasi 5 — Kepemilikan: Dokumen Identitas 9–22 Feb 2025
Focus: Domain Data — Dokumen Identitas
US-14 KTP US-15 Kartu Keluarga US-16 KIA

Laporan kepemilikan dokumen identitas utama: KTP, Kartu Keluarga, dan KIA. Data ini langsung berkaitan dengan target nasional cakupan dokumen kependudukan.

Iterasi 6 — Kepemilikan: Dokumen Akta 23 Feb – 8 Mar 2025
Focus: Domain Data — Akta Sipil
US-17 Akta Kelahiran US-18 Akta Kawin US-19 Akta Cerai

Melengkapi modul kepemilikan dokumen dengan akta sipil: kelahiran, kawin (sipil & agama), dan cerai (sipil & agama). Total 6 jenis dokumen akta.

Iterasi 7 — Struktur Umur Penduduk 9–22 Mar 2025
Focus: Domain Data — Demografi Umur
US-20 Struktur Umur Penduduk US-21 Per Agama US-22 Gol. Darah US-23 Disabilitas US-24 Kepala Keluarga

Modul piramida penduduk & distribusi umur berdasarkan berbagai dimensi: agama, golongan darah, disabilitas, dan kepala keluarga. Mendukung analisis demografis mendalam.

Iterasi 8 — Laporan Pelayanan Bagian I 23 Mar – 5 Apr 2025
Focus: Kinerja Layanan
US-25 Laporan e-KTP US-26 Laporan Capil US-27 Laporan Dafduk

Laporan kinerja pelayanan: e-KTP (cetak), pencatatan sipil (Capil), dan pendaftaran penduduk (Dafduk). Data diambil dari database import Excel.

Iterasi 9 — Laporan & Custom Date Range 6–19 Apr 2025
Focus: Laporan Fleksibel
US-28 Laporan Perekaman US-29 Laporan Online US-30 Custom Range Penduduk US-31 Custom Range Disabilitas US-32 Custom Range Lainnya

Melengkapi modul laporan pelayanan (perekaman & online) dan menambahkan fitur filter rentang tanggal kustom di seluruh laporan utama.

Iterasi 10 — Pencarian & API Internal 20 Apr – 3 Mei 2025
Focus: Interoperabilitas
US-33 Pencarian Data US-06 API Login Passport US-35 API list/search

Fitur pencarian master data lintas jenis, serta pembukaan akses API internal (Passport) untuk sistem eksternal: endpoint login, list jenis data, dan search data.

Iterasi 11 — Integrasi API Eksternal (Dukcapil) 4–17 Mei 2025
Focus: External Integration
US-36 KtpApiService US-37 perekamanService

Integrasi dengan API Dukcapil (ektp.samarindakota.go.id): sinkronisasi data cetak e-KTP via KtpApiService dan data perekaman biometrik via perekamanService menggunakan Guzzle HTTP.
