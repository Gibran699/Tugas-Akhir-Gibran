§ 02

Pengguna Sistem

🧑‍💼
Admin
Pengelola utama sistem. Bertanggung jawab atas manajemen pengguna, pengaturan akses, dan memastikan semua data tersedia serta akurat.
Kelola akun pengguna Atur hak akses fitur Import & hapus data Lihat semua laporan Pantau aktivitas sistem
🧑‍💻
Operator
Petugas lapangan Disdukcapil yang bertugas menginput dan memvalidasi data kependudukan berdasarkan wilayah kerjanya masing-masing.
Upload data Excel Lihat data wilayah Cetak laporan Pantau statistik
§ 03

Modul Fitur Sistem

📊
Agregat DKB
Rekapitulasi data demografis penduduk mencakup jenis kelamin, agama, pekerjaan, pendidikan, status perkawinan, golongan darah, dan disabilitas.
Penduduk Kepala Keluarga Pendidikan Disabilitas Status Kawin
📄
Kepemilikan Dokumen
Pantau tingkat kepemilikan dokumen kependudukan oleh masyarakat Samarinda per kelurahan dan kecamatan.
KTP Kartu Keluarga KIA Akta Kelahiran Akta Nikah Akta Cerai
📈
Struktur Umur Penduduk
Distribusi penduduk berdasarkan kelompok usia, mencakup analisis piramida penduduk, kepala keluarga, agama, golongan darah, dan disabilitas per rentang umur.
Kelompok Umur Umur Tunggal Status Kawin Disabilitas
🔢
Statistik Kelompok Umur
Analisis data per usia tunggal (1 tahun) dengan filter rentang umur kustom. Data dihitung otomatis dari data umur tunggal yang telah diimport.
Rentang Umur Kustom Penduduk Kepala Keluarga Disabilitas
🏛️
Pelayanan Dukcapil
Monitoring data layanan administrasi kependudukan secara online maupun langsung, termasuk perekaman dan pencetakan e-KTP.
Pelayanan Online Cetak e-KTP Perekaman KTP Kinerja Capil Kinerja Dafduk
⚙️ Manajemen Sistem
Kelola akun pengguna, atur peran dan hak akses per fitur, pantau log aktivitas, serta reset password.
Kelola Pengguna Peran & Hak Akses Status Aktif / Nonaktif
📥 Import Data
Unggah data kependudukan dari file Excel (.xlsx) sesuai template resmi. Sistem memvalidasi dan menyimpan data otomatis.
Format Excel .xlsx Template Resmi Validasi Otomatis Pilih Semester & Tahun
🔗 Integrasi Eksternal
Mengambil data pelayanan dari sistem eksternal Disdukcapil secara otomatis menggunakan koneksi API aman.
API Pelayanan Online API e-KTP Samarinda Token Otomatis
§ 04

Cara Kerja Sistem

1
📥
Masukkan Data
Operator mengunggah file Excel data kependudukan atau memilih periode semester & tahun. Data pelayanan diambil otomatis dari sistem eksternal.
Proses
2
⚙️
Sistem Memproses
Sistem memvalidasi data, menyimpan ke database, lalu menghitung agregasi dan statistik per kelurahan dan kecamatan secara otomatis.
Tampilkan
3
📊
Lihat Hasil
Data tersaji dalam bentuk tabel interaktif, grafik, dan ringkasan yang bisa difilter per wilayah, semester, atau tahun sesuai kebutuhan.
§ 05

Tampilan yang Dihasilkan

🗂️
Dashboard Ringkasan
Grafik interaktif ringkasan data kependudukan terkini di seluruh kota
📋
Tabel Per Wilayah
Data terperinci per kelurahan dan kecamatan yang bisa dicari dan diurutkan
📉
Grafik Statistik
Visualisasi piramida umur, perbandingan kategori, dan tren antar periode
🖨️
Laporan & Cetak
Data siap cetak atau ekspor untuk keperluan pelaporan dinas
