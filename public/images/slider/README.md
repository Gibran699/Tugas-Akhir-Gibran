# Slider Images

## Folder ini berisi gambar untuk animated slider background pada halaman login.

### Spesifikasi Gambar:
- **Resolusi:** Minimal 1920x1080px (Full HD)
- **Format:** JPG atau PNG
- **Ukuran file:** Maksimal 500KB per gambar
- **Jumlah:** 3 gambar (slide1.jpg, slide2.jpg, slide3.jpg)

### Tema yang Disarankan:
1. Gedung pemerintahan Kota Samarinda
2. Pemandangan kota Samarinda
3. Infrastruktur digital / teknologi
4. Data visualization backgrounds
5. Landmark Kota Samarinda

### File yang Diperlukan:
```
slide1.jpg
slide2.jpg
slide3.jpg
```

### Cara Menambahkan Gambar:
1. Siapkan 3 gambar sesuai spesifikasi di atas
2. Rename gambar menjadi slide1.jpg, slide2.jpg, slide3.jpg
3. Copy ke folder ini: `public/images/slider/`

### Temporary Placeholder:
Jika belum ada gambar, slider akan menggunakan placeholder atau Anda bisa menggunakan URL dari Unsplash:
- https://source.unsplash.com/1920x1080/?city,technology
- https://source.unsplash.com/1920x1080/?government,building
- https://source.unsplash.com/1920x1080/?data,digital

### Optimasi Gambar:
Untuk performa terbaik, compress gambar menggunakan:
- TinyPNG: https://tinypng.com/
- Squoosh: https://squoosh.app/
- ImageOptim (Mac): https://imageoptim.com/

---

**Note:** Gambar akan ditampilkan sebagai background full-screen dengan overlay gelap untuk meningkatkan kontras dengan form login.
