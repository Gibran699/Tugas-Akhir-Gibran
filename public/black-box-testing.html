AUTENTIKASI (Login, Logout, Ganti Password, Blokir Akun) — US-01 s.d US-04
RDDC-BT-AUTH-01 Login berhasil dengan kredensial valid
  1. Buka halaman /login
  2. Isi email terdaftar dan aktif
  3. Isi password yang benar
  4. Tekan tombol Login
 Pengguna berhasil masuk ke sistem dan diarahkan ke halaman Dashboard sesuai role yang dimiliki Sesuai Pass
RDDC-BT-AUTH-02 Login gagal – email tidak terdaftar
  1. Buka halaman /login
  2. Isi email yang tidak terdaftar di sistem
  3. Isi password sembarang
  4. Tekan tombol Login
 Sistem menampilkan pesan kesalahan "Email tidak terdaftar!" dan halaman login tetap ditampilkan Sesuai Pass
RDDC-BT-AUTH-03 Login gagal – password salah
  1. Buka halaman /login
  2. Isi email terdaftar dan aktif
  3. Isi password yang salah
  4. Tekan tombol Login
 Sistem menampilkan pesan kesalahan "Invalid credentials" dan halaman login tetap ditampilkan Sesuai Pass
RDDC-BT-AUTH-04 Login gagal – akun dinonaktifkan
  1. Buka halaman /login
  2. Isi email akun yang statusnya nonaktif (is_active = false)
  3. Isi password yang benar
  4. Tekan tombol Login
 Sistem menampilkan pesan "Akun Anda telah dinonaktifkan. Hubungi administrator." dan akses ke sistem ditolak Sesuai Pass
RDDC-BT-AUTH-05 Akses halaman terproteksi tanpa login
  1. Buka browser baru (sesi kosong)
  2. Akses langsung URL / (Dashboard)
 Sistem mendeteksi sesi tidak aktif dan mengarahkan pengguna ke halaman login secara otomatis tanpa dapat mengakses halaman yang dituju Sesuai Pass
RDDC-BT-AUTH-06 Logout dari sistem
  1. Login ke sistem dengan akun valid
  2. Klik tombol Logout pada menu navigasi
 Sistem mengakhiri sesi pengguna dan mengarahkan ke halaman login Sesuai Pass
RDDC-BT-AUTH-07 Ganti password berhasil
  1. Login ke sistem
  2. Buka menu pengaturan akun
  3. Isi password lama dengan benar
  4. Isi password baru (min. 8 karakter)
  5. Isi konfirmasi password baru
  6. Tekan tombol Simpan
 Sistem memverifikasi kesesuaian password lama, memperbarui password baru, dan menampilkan notifikasi "Ganti sandi berhasil." Sesuai Pass
RDDC-BT-AUTH-08 Ganti password gagal – password lama salah
  1. Login ke sistem
  2. Buka menu pengaturan akun
  3. Isi password lama dengan nilai yang salah
  4. Isi password baru dan konfirmasi
  5. Tekan tombol Simpan
 Sistem menampilkan pesan kesalahan "Kata sandi yang dimasukkan tidak sesuai dengan kata sandi lama." dan password tidak berubah Sesuai Pass
RDDC-BT-AUTH-09 Ganti password gagal – password baru kurang dari 8 karakter
  1. Login ke sistem
  2. Buka menu pengaturan akun
  3. Isi password lama dengan benar
  4. Isi password baru kurang dari 8 karakter (misal: "abc123")
  5. Tekan tombol Simpan
 Sistem menampilkan pesan validasi bahwa password baru minimal harus 8 karakter; password tidak berubah Sesuai Pass
