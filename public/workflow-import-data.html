Catatan Implementasi Teknis

Penjelasan detail setiap tahapan dalam alur import data

Tahapan Komponen Detail
Validasi Dasar Laravel Validator semester required integer  ·  tahun required integer  ·  file required mimes:xlsx,xls,csv max:20480
Resolusi Kelas Import config/dataArray.php Kelas import dan model dipilih secara dinamis dari listFileImport[keterangan_file] dan listFileModel[keterangan_file]. Setiap jenis data memiliki kelas Maatwebsite Import tersendiri.
Cek Duplikasi Data Eloquent / Query Builder Model::where('tahun', $tahun)->where('semester', $semester)->exists()  — mencegah overwrite data yang sudah ada. Mengembalikan HTTP 409 jika duplikat.
Optimasi File Besar PHP Runtime / Chunk File > 2 MB: ini_set('memory_limit', '1024M'), set_time_limit(600), dan $import->setChunkSize(500) untuk membaca 500 baris per iterasi agar tidak kehabisan memori.
Tipe File Maatwebsite\Excel Ekstensi .xlsx → Excel::XLSX (default)  ·  .xls → Excel::XLS  ·  .csv → Excel::CSV
Transaksi Database DB Facade DB::beginTransaction() sebelum import. Jika sukses → DB::commit(). Jika exception → DB::rollback() + Log::error() ke storage/logs.
Respons JSON HTTP Response 200: "Import berhasil"  ·  409: "Data Sudah ada"  ·  500: "Proses gagal: [pesan error]"
