Alur Data — Import Excel
Admin / Operator → Upload file .xlsx → Middleware (Auth + RBAC) → ImportController + *Import.php → Eloquent menyimpan ke MySQL → SweetAlert2 notifikasi sukses
Alur Data — Tampil Data
Pengguna memilih fitur → jQuery AJAX → CalculateDataController → Eloquent query MySQL + JOIN wilayah → Response JSON → DataTable / ApexChart
Alur Data — External API
Request pelayanan → Service Class (ExternalApiService / KtpApiService) → Bearer Token / Basic Auth → API Eksternal Samarinda → Render tabel pelayanan
