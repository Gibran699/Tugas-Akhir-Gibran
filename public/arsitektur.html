XP Architecture Modelling

🏛️ Metafor Model Arsitektur
Rumah Data 2.0

Arsitektur sistem didefinisikan sebagai serangkaian keputusan yang menentukan struktur dan perilaku sistem. Dalam metode XP, model ini dibuat untuk mempertimbangkan berbagai solusi alternatif sebelum implementasi dilakukan.

💡
1. Metafor Sistem
🏢

Rumah Data sebagai Kantor Dinas Kependudukan Digital

Sistem ini dapat dimetaforkan sebagai sebuah gedung kantor pemerintahan digital yang melayani kebutuhan data kependudukan secara terpusat.

  • 🚪 Pintu Masuk (Login + Middleware) — pos keamanan yang memverifikasi identitas & hak akses petugas
  • 🗺️ Papan Petunjuk (Routes) — mengarahkan setiap permintaan ke ruangan / layanan yang tepat
  • 👨‍💼 Petugas Layanan (Controllers) — memproses setiap permintaan yang masuk dari pengguna
  • 📁 Ruang Arsip (Models + Database) — menyimpan & mengambil data resmi kependudukan
  • 📋 Loket Tampilan (Blade Views) — antarmuka yang dilihat oleh pengguna
  • 📥 Bagian Penerimaan Berkas (Import) — menerima data Excel dari sumber eksternal
  • 🔌 Sambungan Eksternal (Services / API) — penghubung ke sistem luar (KTP, Perekaman)
  • 🔑 Buku Induk Pegawai (Role + Permission) — menentukan siapa yang boleh mengakses ruangan apa

4. Peta Komponen Sistem

🔐 Autentikasi & Akses

  • Auth\MainController (login, logout, ganti password)
  • Middleware: Authenticate, CheckUserActive
  • Session-based authentication
  • spatie/laravel-permission (Role & Permission)
  • Laravel Passport (API token)
  • Laravel Sanctum (SPA auth)

📊 Dashboard & Navigasi

  • MainController → dataDashboard (JSON)
  • Views: dashboard/ (6 views)
  • Code-based view routing (30+ view codes)
  • Sidebar navigasi dinamis

📥 Import Data

  • Maatwebsite Excel 3.1
  • 45 class import terdedikasi
  • Import Agregat DKB (5 kategori)
  • Import Kepemilikan Dokumen (8 jenis)
  • Import Struktur Umur (16 jenis)
  • Import Laporan Kinerja Pdak (2 format)

📦 Domain Model – Data Statistik

  • AgregatDKB: Penduduk, KK, Pendidikan, Disabilitas, StatusKawin
  • Kepemilikan: KTP, KK, AktaKelahiran, AktaKawin, AktaCerai, KIA
  • StrukturUmur: berdasarkan Agama, Disabilitas, GolDarah, Usia
  • LaporanKinerjaFormatPdak (Capil & Dafduk)

🔌 Integrasi Eksternal

  • ExternalApiService (Guzzle HTTP)
  • KtpApiService (verifikasi KTP)
  • perekamanService
  • API endpoint: api.php

👥 Manajemen Pengguna & Wilayah

  • UserController (CRUD + toggle status)
  • RoleController (CRUD)
  • PermissionController
  • WilayahController (kecamatan & kelurahan)
  • Model: User, Role, Permission, DataPengguna
  • Model: WilayahKecamatan, WilayahKelurahan

⚙️ Kalkulasi & Pengolahan Data

  • CalculateDataController (151 KB — logika terbesar)

🗄️ Infrastruktur Data

  • MySQL (via XAMPP)

5. Pertimbangan Solusi Alternatif Arsitektur (XP)
01

Monolithic Laravel MVC

Seluruh sistem dalam satu aplikasi Laravel

✅ Kelebihan

  • Sederhana dan cepat dikembangkan
  • Deployment mudah (satu server)
  • Cocok untuk tim kecil XP
  • Debugging lebih mudah

⚠️ Kekurangan

  • Skalabilitas terbatas
  • Controller bisa menjadi sangat besar
✅ Digunakan saat ini — paling sesuai
02

Modular Monolith

Modul terpisah dalam satu aplikasi Laravel

✅ Kelebihan

  • Setiap modul dapat dikembangkan mandiri
  • Mudah menambah modul baru
  • Test lebih terarah per modul

⚠️ Kekurangan

  • Memerlukan struktur folder yang disiplin
  • Overhead awal lebih tinggi
🔄 Rekomendasi untuk pengembangan lanjutan
03

REST API + Frontend SPA

Backend API Laravel + Frontend React/Vue

✅ Kelebihan

  • Frontend & backend bisa dikembangkan paralel
  • UI lebih responsif (SPA)
  • API bisa dipakai mobile app

⚠️ Kekurangan

  • Kompleksitas tinggi — 2 codebase
  • Overhead autentikasi API (sudah ada Passport)
  • Kurang cocok untuk tim kecil XP saat ini
🔮 Cocok untuk versi 3.0 ke depan

Keputusan Pilihan yang Diambil Dampak pada Struktur Dampak pada Perilaku Status
Framework Utama Laravel 10 + PHP 8.1 (MVC) app/Http, app/Models, resources/views terpisah jelas Request mengalir melalui route → middleware → controller → model → view ✅ Final
Autentikasi Pengguna Session-based Login + Middleware Guard Auth\MainController, CheckUserActive, Authenticate middleware Semua halaman terproteksi — redirect ke login jika belum auth ✅ Final
Otorisasi Hak Akses spatie/laravel-permission (Role & Permission) Model Role, Permission, tabel pivot di database Fitur tertentu dapat di-lock berdasarkan role — can:pengaturan ✅ Final
Import Data Eksternal Maatwebsite Excel 3.1 (45 class Import) Folder app/Imports/ dengan 45 class terdedikasi per jenis data Admin dapat upload file Excel → data masuk ke database secara terstruktur ✅ Final
Struktur Domain Model Model dikelompokkan per kategori data (AgregatDKB, Kepemilikan, StrukturUmur) Folder model hierarkis — mudah diperluas tanpa konflik nama Query data lebih terarah dan semantik sesuai domain kependudukan 🔄 Berkembang
Kalkulasi & Agregasi Data CalculateDataController (dedicated, 151 KB) Logika kalkulasi terpisah dari controller lain Data statistik dapat dihitung ulang kapan saja dari data mentah ⚠️ Perlu refactor
Integrasi API Eksternal Service Layer (ExternalApiService, KtpApiService, perekamanService) app/services/ sebagai abstraksi komunikasi eksternal Controller tidak langsung memanggil HTTP — melalui service class 🔄 Berkembang
API Endpoint Internal Laravel Passport + Sanctum (dual auth) api.php route, API Controller, token management Memungkinkan akses data via API token untuk integrasi sistem lain 🔮 Future-ready
Deployment & Infrastruktur XAMPP (lokal) + Docker support (docker-compose + nginx) Dockerfile, docker-compose.yml, nginx/ config tersedia Aplikasi siap dipindahkan ke server production berbasis container 🔮 Siap migrasi

8. Rekomendasi Model Arsitektur

🏆 Monolithic Modular Laravel MVC

Sistem tetap berada dalam satu aplikasi Laravel, namun setiap domain data dipisahkan menjadi modul yang jelas. Struktur folder mengikuti domain: Agregat DKB, Kepemilikan, Struktur Umur, dan Laporan Pelayanan.

✅ Sesuai dengan struktur project saat ini
✅ Cocok dengan siklus iterasi XP yang pendek
🔄 Siap dikembangkan ke modular tanpa perombakan besar
🔮 API layer sudah tersedia untuk evolusi ke SPA

📌 Stack Teknologi yang Diputuskan

Framework Laravel 10 (PHP 8.1)
Database MySQL via Eloquent ORM
Autentikasi Session + Passport + Sanctum
Otorisasi spatie/laravel-permission
Import Data Maatwebsite Excel 3.1
Frontend Blade + TailwindCSS + Vite
HTTP Client Guzzle 7.x
Deployment XAMPP lokal / Docker (Nginx)
